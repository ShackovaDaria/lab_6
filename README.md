# Домашнее задание к работе 6

## Условие задачи
Составить программу, которая проверяет, принадлежит ли заданная пользователем точка с координатами (x, y) заданной закрашенной (заштрихованной) области, и выводит на экран соответствующее сообщение.

## 1. Алгоритм и блок-схема

### **Математическое описание:**

Для начала определим уравнения линий, которые формируют границы заштрихованной фигуры.

**Линия сверху (прямая):** Она проходит через координаты (-5; 0) и (0; 5). Воспользуемся формулой прямой y = kx + b.
   - Свободный член b = 5.
   - Подставляем координаты: 0 = k * (-5) + 5, откуда k = 1.
   - Итоговое уравнение: y = x + 5.

**Линия снизу (дуга):** Она описывается уравнением \(x^2 + y^2 = 3\). Поскольку искомая область расположена над осью OX (в верхней полуплоскости), выразим y:
   - y = √(3 - x²).

Таким образом, искомая область находится под верхней прямой (y ≤ x + 5) и над дугой окружности (y ≥ √(3 - x²)). Также она ограничена осью ординат (x = 0) и осью абсцисс (y = 0), так как штриховка идет до этих осей.



### **Алгоритм**
1. **Старт.**
2. Подключить библиотеки:
   - `<stdio.h>` — для операций ввода-вывода (printf, scanf).
   - `<locale.h>` — для корректного отображения кириллицы.
   - `<math.h>` — для вычисления квадратного корня (функция sqrt).
3. Объявить прототип функции `int dz(float x, float y)`, которая будет проверять попадание точки в область.
4. Описать функцию `main()`:
   - Создать переменные `x1`, `y1` (тип float) для координат и `result` (тип int) для результата.
   - Включить русскую локаль: `setlocale(LC_ALL, "Ru")`.
   - Запросить у пользователя ввод координат с помощью `scanf`.
   - Передать введенные значения в функцию `dz`.
   - Проверить возвращенное значение: если 1 — вывести сообщение о принадлежности, иначе — о том, что точка вне области.
   - Вернуть 0 (успешное завершение).
5. Внутри функции `dz`:
   - Проверить, не выходит ли точка за рамки прямоугольника (x > 0, x < -5, y > 5, y < 0). Если да — вернуть -1.
   - Проверить, не оказалась ли точка выше верхней прямой: y > 1.0 * x + 5.0. Если да — вернуть -1.
   - Проверить, не попала ли точка под дугу окружности: x*x + y*y < 3.0. Если да — вернуть -1.
   - Если все проверки пройдены, значит точка внутри — вернуть 1.
6. **Завершение.**

## 2. Реализация программы
```c
#include <stdio.h>
#include <locale.h>
#include <math.h>

int dz(float x, float y);

int main() {
    setlocale(LC_ALL, "Ru");
    
    float x1, y1;
    printf("Введите x: ");
    scanf("%f", &x1);
    printf("Введите y: ");
    scanf("%f", &y1);
    
    int result = dz(x1, y1);
    
    if (result == 1) {
        printf("Точка (%.2f, %.2f) принадлежит области\n", x1, y1);
    }
    else {
        printf("Точка (%.2f, %.2f) не принадлежит области\n", x1, y1);
    }
    
    return 0;
}

int dz(float x, float y) {
    // 1. Ограничивающий прямоугольник
    if (x > 0 || x < -5 || y > 5 || y < 0) {
        return -1;
    }
    // 2. Проверка на нахождение выше верхней прямой
    if (y > 1.0 * x + 5.0) {
        return -1;
    }
    // 3. Проверка на нахождение внутри окружности (ниже дуги)
    if (x*x + y*y < 3.0) {
        return -1;
    }
    
    // Если все проверки пройдены - точка внутри
    return 1;
}
```
